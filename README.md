# \# 🛒 Amazona E-Commerce

# 

# A full-stack e-commerce web application inspired by Amazon, built with the MERN stack.

# 

# The project provides a complete shopping experience with product browsing, search, cart management, user authentication, checkout, order management, and administrative features.

# 

# \## 🚀 Features

# 

# \### 👤 User Features

# \- User registration and login

# \- User profile management

# \- Product browsing

# \- Product search

# \- Product ratings and reviews

# \- Shopping cart

# \- Shipping address management

# \- Multiple payment method selection

# \- Order placement

# \- Order history

# \- Order details

# 

# \### 🛍️ E-Commerce Features

# \- Product listing

# \- Product details

# \- Product search

# \- Product categories

# \- Product ratings

# \- Shopping cart

# \- Checkout process

# \- Order management

# 

# \### 👨‍💼 Admin Features

# \- Admin dashboard

# \- Manage users

# \- Manage products

# \- Edit products

# \- Manage orders

# \- View order information

# 

# \### 🏪 Seller Features

# \- Seller dashboard

# \- Seller product management

# \- Seller order management

# 

# \### 💬 Additional Features

# \- Support / chat functionality

# \- Map screen

# \- Protected routes

# \- Role-based access

# \- Image upload functionality

#
